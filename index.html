Import Data Inventaris (.csv)

Unggah file CSV dengan kolom sesuai template. Data akan ditinjau dan divalidasi sebelum ditambahkan ke daftar inventaris.

Aturan Format Import:
  • Gunakan template resmi agar header kolom sesuai otomatis.
  • Jenis barang wajib: BARANG MODAL / ASET, BARANG HABIS PAKAI, UMUM, atau ATK.
  • Jurusan wajib: TKJ, TSM, TKR, atau UMUM.
  • Untuk buku pelajaran, cantumkan Judul Buku dan Kelas.

Export CSV & Paket ZIP

Unduh data inventaris sebagai CSV atau paket ZIP yang berisi CSV dan berkas manifest. CSV dapat dibuka dengan aplikasi spreadsheet.
